# Contributing

## Branch Naming

Branches should follow this format:

discription-in-three-words-or-less

## Commits

Use: Added:, Changed:, Removed:,

Examples:
Added: A menu button
I added a menu button inside the nav on the front page that directs you to the bottom of the page.


## Pull Requests

- All changes must be made through a pull request.
- Do not push directly to `main`.
- At least 1 other team member must approve the PR.
- Explain what was changed in the PR.
- Make sure the website works before pushing.

## HTML Naming

- filenames: kebab-case
- comments: UPPERCASE WITH SPACES
- classes: kebab-case
- ids: kebab-case

## CSS Naming

- comments: UPPERCASE WITH SPACES

## JS Naming

- comments: UPPERCASE WITH SPACES
- variables: camelCase
- classes: PascalCase
- functions: camelCase
